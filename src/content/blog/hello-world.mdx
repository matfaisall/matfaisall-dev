## Writing a new post

1. Create `src/content/blog/<slug>.mdx`. The file name becomes the URL: `/blog/<slug>`.
2. Export `metadata` at the top with `title`, `summary`, `publishedAt` and `tags`.
3. Register it in `src/features/blog/posts.ts`.

| Field         | Required | Example              |
| ------------- | -------- | -------------------- |
| `title`       | yes      | `"Hello, world"`     |
| `summary`     | yes      | One sentence         |
| `publishedAt` | yes      | `"2026-10-23"`       |
| `updatedAt`   | no       | `"2026-11-01"`       |
| `tags`        | yes      | `["Next.js"]`        |
| `draft`       | no       | `true` hides it in production |
