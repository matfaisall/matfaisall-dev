# Colors

Brand colour is **amber**; neutrals are **stone**. Every value is a CSS variable defined in
`src/app/globals.css` and exposed to Tailwind as a semantic utility (`bg-primary`,
`text-muted-foreground`, …). The swatches show the light theme; the dark values live in the
`.dark` block of the same file. Switch the toolbar theme on any component story to see them applied.
